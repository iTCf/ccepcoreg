## Simultaneous stereo-EEG and high-density scalp EEG recordings to study the effects of intracerebral stimulation parameters

This repository contains example usage demonstration scripts and the code used for data curation for the article [Simultaneous stereo-EEG and high-density scalp EEG recordings to study the effects of intracerebral stimulation parameters](https://www.sciencedirect.com/science/article/pii/S1935861X22000675) and the corresponding dataset [Dataset on (OSF)](https://osf.io/wsgzp/overview).
